# 🌙 React Dark Theme

Um projeto simples desenvolvido para praticar gerenciamento de tema (Dark/Light) utilizando React, Context API, TypeScript e LocalStorage.

## 🚀 Tecnologias

- React
- TypeScript
- Context API
- useState
- LocalStorage
- Tailwind-CSS

---

## 📚 O que foi praticado

- Compartilhamento de estado global com Context API
- Gerenciamento de estado utilizando useState
- Persistência do tema com LocalStorage
- Manipulação de eventos
- Componentização
- Organização de código em React

---

## ✨ Funcionalidades

- Alternar entre tema Claro e Escuro
- Persistência do tema mesmo após atualizar a página
- Interface simples e responsiva

---

## 🎯 Objetivo

Este projeto foi desenvolvido durante meus estudos de React para consolidar os conceitos de:

- Context API
- Estado Global
- Persistência de dados
- Organização de componentes
